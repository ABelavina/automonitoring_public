# Демо системы автомониторинга 
(чувствительная информация скрыта серым)

Система состоит из SAS/Python-скриптов, планировщика задач, БД и BI-системы.
Для каждой модели разработан отдельный скрипт сбора данных и расчета метрик.
Результаты выполнения скриптов сохраняются в БД. Для визуализации этой информации используется несколько дашбордов с разным уровнем детализации.

## Основной дашборд (общая информация по всем моделям)
<img width="1919" height="936" alt="Clipboard - 31 июля 2025 г , 18_06" src="https://github.com/user-attachments/assets/13cd9014-51ae-4f57-b5c6-8c7ae86761df" />

На дашборде отображаются график со статистикой «светофоров» в разрезе двух типов моделей и таблица с подробной информацией.
В таблице для каждого отчетного месяца выведены итоговые статусы моделей («светофоры»), а также статусы по разделам: стабильность, предсказательная способность и динамика.

Сводный график и таблица взаимосвязаны: для уточнения информации на графике достаточно выбрать интересующий блок, и данные в таблице автоматически отфильтруются.
Например, при выборе «красного» статуса модели на отчетную дату 07.2025:
<img width="1919" height="928" alt="Clipboard - 31 июля 2025 г , 18_191" src="https://github.com/user-attachments/assets/0f1dd2f7-ad1b-4ff4-90a4-9c658b1bf587" />

Для более гибкой фильтрации на дашборд выведены фильтры по отделу разработки, названию модели, типу модели и категории «светофора».
